# Анализ A/B-теста: новая посадочная страница интернет-магазина

## Описание проекта

Анализируем A/B-тест для посадочной страницы интернет-магазина. Компания сравнила старую страницу с новой и хотела понять, улучшает ли новая версия конверсию пользователей.

## Ход Работы

8. Сегментный анализ по странам
9. Финальная бизнес-рекомендация

## Бизнес-вопрос

**Стоит ли компании раскатывать новую посадочную страницу на всех пользователей?**

## Данные

В проекте используются два CSV-файла из датасета Kaggle для A/B-тестирования:

- `data/raw/ab_test.csv`
- `data/raw/countries_ab.csv`

Основные колонки:

| Колонка | Описание |
|---|---|
| `id` | ID пользователя |
| `time` | Время события |
| `con_treat` | Экспериментальная группа: `control` или `treatment` |
| `page` | Версия страницы: `old_page` или `new_page` |
| `converted` | Флаг конверсии: 0 или 1 |
| `country` | Страна пользователя |

## Основная метрика

Главная метрика проекта — **Conversion Rate**.

```text
Conversion Rate = пользователи с конверсией / все пользователи
```

## Проверка корректности эксперимента

В исходном датасете было:

- 294 478 строк
- 290 584 уникальных пользователя
- 3 894 лишние строки из-за повторяющихся пользователей
- 1 895 пользователей, попавших сразу в обе экспериментальные группы

В ходе анализа были удалены:

- пользователи, попавшие одновременно в `control` и `treatment`;
- некорректные пары группа-страница;
- оставшиеся дубликаты пользователей.

Итоговый очищенный датасет:

- 288 688 уникальных пользователей
- 144 300 пользователей в группе `control`
- 144 388 пользователей в группе `treatment`

Корректное соответствие групп и страниц:

```text
control   -> old_page
treatment -> new_page
```

## Основные результаты

| Группа | Пользователи | Конверсии | Conversion Rate |
|---|---:|---:|---:|
| control | 144 300 | 17 360 | 12.03% |
| treatment | 144 388 | 17 158 | 11.88% |

Наблюдаемый эффект:

- Абсолютная разница: -0.147 процентного пункта
- Относительный uplift: -1.22%
- p-value z-теста: 0.2228
- 95% доверительный интервал для разницы `treatment - control`: [-0.384; 0.089] процентного пункта
- p-value проверки SRM: 0.8699

## Вывод

В группе `treatment` конверсия оказалась немного ниже, чем в группе `control`. Однако эта разница статистически незначима на уровне значимости 5%.

95% доверительный интервал включает 0, поэтому наблюдаемая разница может быть объяснена случайными колебаниями.

## Бизнес-рекомендация

На основании текущих результатов A/B-теста новую посадочную страницу **не рекомендуется раскатывать на всех пользователей**.

Новая страница не показала статистически значимого улучшения конверсии. Кроме того, наблюдаемая конверсия в группе `treatment` немного ниже, чем в группе `control`.
